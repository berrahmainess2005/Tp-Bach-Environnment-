TP N° 2 : Introduction aux scripts Bash et à l'analyse des données environnementales avec Python

==================================================
EXERCICE 1 : Découverte de Bash et Git Bash
==================================================
Question : Quel est l'intérêt d'utiliser des commandes Bash plutôt que de réaliser toutes ces opérations manuellement avec l'explorateur Windows ?

Réponse :
L'intérêt principal est l'automatisation des tâches répétitives, un gain de temps considérable, la réduction des erreurs humaines et la possibilité de manipuler rapidement un grand nombre de fichiers et dossiers.

==================================================
EXERCICE 2 : Création et exécution d'un script Bash
==================================================
Question : Quelle est la différence entre exécuter une commande directement dans le terminal et exécuter plusieurs commandes enregistrées dans un script Bash ?

Réponse :
Exécuter une commande dans le terminal réalise une action unique et immédiate qui doit être retapée à chaque fois. En revanche, un script Bash (.sh) regroupe une suite de commandes sauvegardées dans un fichier, permettant de les exécuter automatiquement, en série et de manière reproductible en une seule fois.

==================================================
EXERCICE 3 : Automatisation de l'exécution d'un programme Python
==================================================
Question 3 : Expliquer comment Bash permet d'automatiser l'exécution d'un programme Python.

Réponse :
Le script Bash agit comme un chef d'orchestre : il prépare d'abord l'environnement (création de dossiers, affichage de messages, gestion des fichiers) puis appelle directement l'interpréteur Python (via la commande "python analyse.py") pour lancer le traitement des données automatiquement sans intervention manuelle.

Question 4 : Proposer une application de cette automatisation dans un laboratoire environnemental.

Réponse :
Dans un laboratoire environnemental, on peut automatiser le traitement quotidien des relevés de capteurs (qualité de l'air ou de l'eau) : le script Bash crée automatiquement le dossier daté du jour, sauvegarde les données brutes, lance un script Python pour calculer les moyennes et détecter les seuils de pollution, puis génère un rapport final.
